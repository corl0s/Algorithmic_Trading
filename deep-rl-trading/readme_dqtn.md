# Deep RL Trading Agent (DQTN)

To install all the related dependencies, run:
```pip
pip install requirements.txt
```

## To train the code, run:

```python
python main.py
```

## To test the code, run:

```python
python test.py
```

Most dependencies are satisfied and you should be able to run the code directly. This is a comprehensive understanding method of using Deep Q Network along with Transformers using stocks.
